# プロジェクト定義

## サービス概要

**麻雀パズル（Mahjong Puzzle）** は、日本の麻雀牌を題材にした落ち物パズルゲームです。プレイヤーは落下する牌を配置し、同種 3 枚（刻子）や連続数牌（順子）を隣接させて消去します。麻雀の「役」を参考にした高得点コンボを狙える設計です。

## 価値仮説

| 観点 | 内容 |
|------|------|
| エンタメ | 麻雀の牌感覚を、テトリス系の手軽な操作で楽しめる |
| 学習 | 役ガイドで麻雀用語・牌の組み合わせに触れられる |
| 対戦 | オンライン対戦で他プレイヤーとリアルタイム競争（計画） |
| 収益 | モバイル／ウェブ向け広告収入モデル（計画） |

## ターゲットユーザー

- 麻雀に興味があるが、本格対局のハードルを感じるカジュアルプレイヤー
- 落ち物パズル好きで、テーマ性のあるゲームを求めるユーザー
- 短時間でスコアや対戦を楽しみたいモバイル／ブラウザユーザー

## 提供形態

- **プラットフォーム**: Web（Next.js App Router）。モバイルブラウザ対応を想定
- **モード**: シングルプレイ（練習）、オンライン対戦（ロビー・部屋）
- **言語**: UI は日本語中心（牌表示・役名は日英併記）

## ビジネスモデル（方針）

- 無料プレイ + 広告収入（インタースティシャル・リワード広告等は未実装）
- マルチプレイはサーバー運用コストを考慮し、スケーラブルなリアルタイム基盤で構築する

## 成功指標（目標）

| KPI | 説明 |
|-----|------|
| セッション継続 | 1 プレイあたりの平均プレイ時間 |
| リテンション | 再訪率（D1 / D7） |
| 対戦成立率 | ロビー入室から対戦開始までの成功率（マルチ本番化後） |
| 収益 | ARPDAU（広告実装後） |

## スコープ外（現時点）

- 麻雀の本格ルール（門前・鳴き・点数計算表）
- ランキング・課金・ソーシャルログイン（将来検討）
- ネイティブアプリ（Web 優先）
