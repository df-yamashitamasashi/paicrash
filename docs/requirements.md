## 非機能要件

### NFR-1 性能

| ID | 要件 | 目標 |
|----|------|------|
| NFR-1.1 | ゲームループ | 60fps 相当の滑らかな UI（tick 間隔はレベル依存） |
| NFR-1.2 | 初回表示 | LCP をモバイル 3G 相当でも許容範囲 |
| NFR-1.3 | マルチレイテンシ | 同期イベント 200ms 以内 |

### NFR-2 可用性・信頼性

| ID | 要件 | 目標 |
|----|------|------|
| NFR-2.1 | 切断時 UX | 明示的エラー・自動再接続（最大 8 回、指数バックオフ） |
| NFR-2.2 | セッション復元 | ブラウザリロード後に localStorage トークンで状態復元 |
| NFR-2.3 | サーバー再起動 | セッション消滅を許容（メモリ管理の制約として明示） |

### NFR-3 セキュリティ

| ID | 要件 | 目標 |
|----|------|------|
| NFR-3.1 | 通信暗号化 | 本番環境は TLS 1.2 以上（`wss://`）、ALB で終端 |
| NFR-3.2 | ゲーム状態 | スコア・牌面の真実はサーバー権威のみ |
| NFR-3.3 | 入力検証 | ニックネーム・ルーム名・チャットのサニタイズ（実装済） |
| NFR-3.4 | レート制限 | セッション作成 10/分、チャット 20/分、ゲーム入力 120/10 秒 |
| NFR-3.5 | WAF | AWS WAF（IP レート制限 + AWSManagedRulesCommonRuleSet） |
| NFR-3.6 | 個人情報 | メールアドレス・パスワード・実名を収集しない |

### NFR-4 アクセシビリティ

| ID | 要件 | 目標 |
|----|------|------|
| NFR-4.1 | キーボード操作 | ゲーム操作のキーボード対応（実装済） |
| NFR-4.2 | スクリーンリーダー | Radix UI コンポーネントの ARIA 活用 |
| NFR-4.3 | コントラスト | WCAG 2.1 AA 相当を目標 |

### NFR-5 品質・保守

| ID | 要件 | 目標 |
|----|------|------|
| NFR-5.1 | TypeScript | `strict: true` |
| NFR-5.2 | Lint | `pnpm lint` 通過 |
| NFR-5.3 | 型チェック | `pnpm exec tsc --noEmit` 通過 |
| NFR-5.4 | テスト | vitest + fast-check によるプロパティベーステスト（実装予定） |

### NFR-6 インフラ・運用

| ID | 要件 | 目標 |
|----|------|------|
| NFR-6.1 | IaC | AWS CDK (TypeScript) で全インフラを管理 |
| NFR-6.2 | CI/CD | GitHub Actions + OIDC 認証（長期アクセスキー不使用） |
| NFR-6.3 | コンテナ | Dockerfile マルチステージビルド（devDeps 除外） |
| NFR-6.4 | 監視 | CloudWatch メモリアラーム（> 80%） |
| NFR-6.5 | スケール | 単一 ECS タスク（desired: 1）、同時接続 100 以下を目安 |

## 技術制約

- パッケージマネージャ: **pnpm**
- フレームワーク: Next.js 16 App Router、React 19
- 状態管理: Zustand（`game-store.ts` / `multiplayer-store.ts`）
- リアルタイム: Socket.IO（`server/index.ts` + `socket.io-client`）
- インフラ: AWS CDK (TypeScript)
- CI/CD: GitHub Actions + OIDC
